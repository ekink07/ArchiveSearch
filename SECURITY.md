# Security policy

## Supported versions

Only the latest release of Arşiv Ara receives fixes. Please update before reporting a problem.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/ekink07/ArchiveSearch/security/advisories/new)
(*Security › Report a vulnerability*).

Include the version (*About*, `F1`), the Windows version and, if possible, a sample archive or steps that reproduce the
problem. You will get an answer as soon as possible; once a fix is released, the report is credited in the
[changelog](CHANGELOG.md) unless you prefer otherwise.

Examples of what counts: an archive that makes the app write files outside the chosen folder, run code, or crash in a
way that could be exploited; passwords stored by the app becoming readable by other users; the installer or the
release files being replaceable.
